# Snap! v0.0.2

カニのハサミで釣り糸を切って、魚を守ろう。
60秒の間に、どれだけ魚を救えるかな？

| ボタン | 操作 |
| --- | --- |
| 十字キー | 左右に泳ぐ・下で潜る |
| A | 両手のハサミで緑の糸を切る |
| B | 押すたびにふわっと浮上 |
| START | 開始・ポーズ・再挑戦 |
| SELECT | タイトルで練習モード・結果からタイトルへ |

釣り糸の緑の部分に、左右どちらかのハサミを重ねてA。
Bは押して離す操作を繰り返すと、浮上を続けられます。
通常モードと練習モードは、それぞれ最高点を保存します。

Web版は、←→で泳ぐ・↓で潜る・Xでハサミ・Z連打で浮上。
Enterで開始・ポーズ、Shiftで練習モードを選べます。
